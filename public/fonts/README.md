# Geist fonts

These are the Geist and Geist Mono variable WOFF2 subsets already used by this project, copied from its successful Next.js build. Their original Unicode ranges are preserved in app/fonts.css, including Cyrillic.

Source: https://github.com/google/fonts/tree/main/ofl/geist and https://github.com/google/fonts/tree/main/ofl/geistmono . Fonts are distributed under the SIL Open Font License 1.1; see the accompanying license files.
